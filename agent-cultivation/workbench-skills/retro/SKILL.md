# retro

按 S9 执行:
1. 确认: 目标、实际结果数据、产出链接、失败点、成员自评。
2. 输出复盘表: 目标｜结果｜差距｜根因｜保留做法｜停止做法｜下次实验。
3. 每条经验按「三层固化」判定去处: 机械可防→代码/检查脚本；每次执行要守的规律→写进agent/skill定义；跨session事实→CLAUDE.md或文档。
4. 给出能力矩阵自评建议分，存 logs/weekly/retro-W{NN}.md。复盘不得只写感受。
