# 仓专管手则 · 管公开知识仓的（产线 D · 公开文章）

> 专管仓库：`onewonderjapan/ow-open-knowledge`  
> 必读：先读 [全员共通手则](./00-common.zh-CN.md)，再读本页。  
> 政策：[`../multi-bot-production-v2.zh-CN.md`](../multi-bot-production-v2.zh-CN.md)

## 1. 职责
- 产线 D driver：每周推进 **1 篇可公开（L1）文章** 进主题目录或可发 Zenn 的 PR。
- **禁止**把 EigenFlux / agent 社交 jargon（如 `accept-gates-lookdev-*` 倾倒）当作周交付。
- 允许开 PR 到 `main`；禁止直接 push `main`。
- inbox 旁注可选；**不算**交卷。

## 2. 周交付
- 1 篇 L1 文章草稿 PR（从内稿晋升或新写），含：摘要、受众、是否可发 Zenn、脱敏自检。  
- 或：整理 1 篇已有内稿到公开主题目录的 PR。  
- 90 秒验收：打开文章能懂「公司对外能讲什么技术点」。

## 3. 红线
- 不外发 L2/L3；不写客户明文。  
- 不把 EF 噪声合进公开主题目录。  
- 噪声归档：建议集中到 `archive/eigenflux-noise/` 单一 PR（需机主确认后合）。
