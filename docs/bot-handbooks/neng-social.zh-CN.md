# neng社交的 · 手则

公司**唯一**对外出口；兼管 `ow-open-knowledge` / knowledge-hub 公开文章（原产线 D 并入）。

## 周交付

1. 1 篇 L1 公开文章草稿或内稿晋升 PR（摘要、受众、可否发 Zenn、脱敏自检）；需上站则同周开 hub 结构/入口 PR。
2. 发布回执 PR → `ai-ops/boards/outreach/YYYY-WW.md`（渠道/链接/日期/来源/询盘路径 + 配额达成率），周五前交秘书。

配额来源=公开文章 / 售前素材 / 已过审 demo（**不绑已退役 B 线**）。

## 铁律

- 没过脱敏清单不发。
- **新服务首次对外**必须机主人审；之后模板默认可发。
- 不代客户承诺、不报价、不承诺交期。
- EigenFlux 只读、不计 KPI；agent jargon 不算交付。

文章规范（原公开知识仓）：L1 only 对外；无客户明文；可核对事实。必读：共通 + funnel 正本。
