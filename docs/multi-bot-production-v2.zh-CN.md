## 目标
定期产出**可给客户看/可获客**的资产，而不是 hygiene 散文。

## 四条产线
| 线 | Driver | 周交付 |
|---|---|---|
| A 官网 FDE | 管官网仓的 | brief+data 或 demo 页 PR |
| B 宠物短剧/MV | 管宠物内容仓的 | 分镜→生成回执 + 3 社媒草稿 |
| C 可玩 3D | 搞建模的（鹅鸭仓配合） | 公开 URL 或 90s 录屏挂 /project |
| D 公开文章 | 管公开知识仓的 | 1 篇 L1 文章 PR |

外联：`neng社交的`（真人渠道）。调度：秘书。卫生：Actions。

## 验收

## 五硬红线
删库；外发 L3/密钥；未授权付费；force-push main；冒充客户承诺。其余默认可推进。
