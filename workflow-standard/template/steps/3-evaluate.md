# 阶段③ 评估 / 采点 (Evaluate)

**目标**：对**过去**的决策，用后续真实行情打分。决策好坏要等时间揭晓。

## 步骤
1. 从 `state/ledger.jsonl` 找出到今日已可评估的历史决策（如昨日/更早）。
2. 用今日真实行情计算兑现结果。
3. 按**预先固定**的指标口径打分，追加一行到 `state/scorecard.jsonl`：
   - 收益：当日/累计模拟收益率、相对基准超额。
   - 风险：最大回撤、波动、单仓集中度。
   - 决策质量：命中率、盈亏比、决策是否被后续行情证伪。
   - 附：本条评分对应哪些 `decisions`、哪条策略条款。

## 产出
- `state/scorecard.jsonl` 追加（含 `run_key`/`ts`/`schema_version`）。

## 约束
- 指标口径**先定义后优化**，不得为了好看中途改口径（STANDARD.md §8）。
- 只评估、不改策略——改策略是阶段④的事。
