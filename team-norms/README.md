# team-norms — Team Norms

Three foundational norms used for onboarding new members (originals in Japanese): Git conventions, Teams chat manners, and business email basics.

## Contents

| Document | What it covers |
|----------|----------------|
| [Git 使用規範ドキュメント.md](Git%20使用規範ドキュメント.md) | Branch model (main / develop / feature / hotfix / release / exp), commit message conventions, a complete rebase guide, disaster recovery |
| [Teamsチャットマナー.md](Teamsチャットマナー.md) | Chat manners: greet first, point first, response-time expectations, thread usage |
| [ビジネスメール基礎.md](ビジネスメール基礎.md) | Business email basics: internal and external formats, structure, example emails |

## Reading order

First week on the team, in order: Git conventions (engineering discipline) → Teams manners (daily communication) → business email (external interface).
